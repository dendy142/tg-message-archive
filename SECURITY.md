# Безопасность

Бот хранит чужую личную переписку, поэтому об уязвимостях просим сообщать приватно.

## Как сообщить

Откройте вкладку **Security → Report a vulnerability** этого репозитория (приватный отчёт
GitHub). Публичный issue или pull request для этого не подходят: до исправления описание
уязвимости увидят все.

В отчёте пригодятся:

- что именно можно сделать и чьи данные это затрагивает;
- шаги воспроизведения или пример запроса;
- версия или коммит, на котором проверяли.

## Что считается уязвимостью

- доступ к данным другого владельца (нарушение изоляции по `owner_user_id`);
- обход проверки `initData` или вызов команд оператора не из консоли оператора;
- внедрение HTML/скриптов через текст сообщений, имена и подписи;
- утечка токенов или содержимого сообщений в логи, уведомления оператору и экспорт.

## Чего здесь нет

- Поддерживается только последняя версия из ветки по умолчанию.
- Вознаграждения за найденные уязвимости не выплачиваются.
- Репозиторий — это код. За данные конкретного инстанса (чужого бота, развёрнутого из этого
  кода) отвечает его оператор — обращайтесь к нему.

## Оператору инстанса

- CLI-токен (`TGCLOUD_TOKEN`) даёт полный доступ к коду и базе бота. Храните его только в
  секретах репозитория; при подозрении на утечку перевыпустите в @BotFather.
- Адрес Mini App (`setAppUrl`) должен вести на ваш инстанс: по нему уведомления открывают
  приложение с данными входа владельца.
