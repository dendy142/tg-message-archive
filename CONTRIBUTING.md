# Участие в разработке

Спасибо, что хотите помочь проекту. Ниже — как сообщить об ошибке, предложить улучшение и
прислать изменения.

## Ошибки и предложения

- **Ошибка.** Откройте issue и опишите: что делали, что ожидали, что получилось, версию из
  Настроек Mini App. Не прикладывайте содержимое чужой переписки, токены и адрес своего
  инстанса — замените их условными значениями.
- **Идея.** Откройте issue с описанием задачи, которую хотите решить, — до того, как писать
  код: так проще договориться о подходе.
- **Уязвимость.** Не в issue. Порядок приватного сообщения — в [SECURITY.md](SECURITY.md).

## Как собрать проект

Нужен Node.js 20 или новее.

```bash
npm install
npm test          # тесты бэкенда и Mini App
npm run build     # сборка Mini App
```

Локально сервер не запускается: код из `tgcloud/` исполняет платформа, а тесты работают на её
замене из `sdk-shim/`. Чтобы проверить изменения на живом боте, разверните собственный
тестовый инстанс по [docs/deploy.md](docs/deploy.md).

## Перед тем как прислать изменения

Убедитесь, что проходят все проверки — их же запускает CI:

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm run e2e
```

Для `npm run e2e` один раз установите браузер: `npx playwright install chromium`.

## Правила кода

- **Модули платформы.** Правила импортов, базы и деплоя описаны в [AGENTS.md](AGENTS.md).
  Главное: в `tgcloud/` доступны только `sdk` и модули проекта, относительные импорты пишутся
  с расширением `.js`, каждый вызов базы — с `await`.
- **Лимит модулей.** Платформа принимает не больше 100 модулей в `tgcloud/`. Новую логику
  добавляйте в подходящий модуль `lib/`, а не отдельным файлом.
- **Схема базы.** Меняется только в `tgcloud/schema.js`. Удаление колонки, таблицы или индекса —
  через `.deprecated('причина')`.
- **Тексты.** Всё, что видит пользователь, идёт через словари: `tgcloud/lib/i18n.js` для бота и
  `web/src/i18n/` для Mini App. Каждый ключ нужен и в русском, и в английском словаре — это
  проверяют тесты.
- **Тесты.** Исправление ошибки сопровождайте тестом, который без исправления падает. Новое
  поведение — тестом, который его описывает.
- **Ничего от своего инстанса.** В коде, тестах и документах не должно быть адресов Mini App,
  username ботов, числовых id и токенов. Настройки инстанса задаются при деплое.
- **Язык.** Комментарии, тексты коммитов и документы — на русском. `AGENTS.md` и
  `docs/tgcloud-sdk.md` взяты из шаблона платформы и остаются на английском.

## Pull request

- Одна тема на один pull request.
- В описании — что изменено и зачем; если меняется поведение для пользователя или оператора,
  добавьте запись в раздел «Unreleased» файла [CHANGELOG.md](CHANGELOG.md).
- Проверки CI должны быть зелёными.
