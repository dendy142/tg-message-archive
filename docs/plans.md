# Тарифы и подписка Telegram Stars

**Статус: код готов, монетизация выключена.** Пока оператор не задал цену (`app_meta.price_stars`
пусто), у всех пользователей Pro, ограничений нет, а таблица `subscriptions` пустует.

## Что решает оператор

Ниже — значения по умолчанию, зашитые в `tgcloud/lib/plans.js` (`FREE_LIMITS`, `TRIAL_DAYS`). Перед
включением подтвердите их или поменяйте константы.

| | Free | Pro |
|---|---|---|
| Отслеживаемых чатов | 3 | без лимита |
| Срок хранения | до 30 дней | любой, в т. ч. «всегда» |
| Экспорт | только JSON | HTML, JSON, CSV, Markdown |
| «Прислать все файлы чата» | нет | да |
| PIN-код замка | нет | да |

- **Цена** — `N` ⭐ за 30 дней (Telegram принимает у подписок только период 2 592 000 с).
- **Пробный период** — 14 дней Pro. Его получает каждый при первом обращении после включения
  монетизации, в том числе уже подключённые пользователи.
- **Мягкий режим Free.** Ничего не удаляется. Уже архивируемые чаты пишутся дальше. Новый чат
  сверх лимита помечается исключённым (`chat_prefs.excluded_by_plan`), раз в сутки приходит
  напоминание. Оплата снимает такие исключения. Срок хранения, заданный на Pro, при переходе на
  Free не урезается, но поменять его можно только на значение до 30 дней.
- `eraseOwner` подписку не стирает: это запись об оплате (нужна для возврата), иначе удаление
  данных давало бы новый пробный период.

## Включение

1. Контакт поддержки (обязателен по правилам Telegram для ботов с платежами, его показывает
   `/paysupport`): `npm run admin -- '{"setPaySupport": "@username"}'`.
2. Цена: `npm run admin -- '{"setPrice": 99}'`. Без шага 1 команда откажет.
3. Проверить покупку в [тестовой среде](https://core.telegram.org/bots/payments-stars#testing-payments)
   Telegram: Настройки → Подписка → «Оформить Pro». После оплаты должна прийти «⭐ Pro активен»,
   а в Настройках — «Продлевается сама · до …».

Выключить: `'{"setPrice": null}'` — все снова Pro, записи подписок остаются.

## Поток оплаты

1. Mini App → endpoint `subscribe` → `createInvoiceLink` (`currency: "XTR"`, `subscription_period`)
   → `Telegram.WebApp.openInvoice`.
2. `handlers/pre_checkout_query` принимает счёт, только если `invoice_payload` = `pro:<user id>`
   плательщика, валюта XTR и сумма равна текущей цене.
3. `message.successful_payment` (первая оплата и каждое продление) → `subscriptions`: `active`,
   `expires_at` = `subscription_expiration_date`, `charge_id` = `telegram_payment_charge_id`.
4. Отмена из приложения — `editUserStarSubscription(is_canceled)`: статус `cancelled`, Pro до
   конца оплаченного срока.
5. Возврат — только оператором: `'{"refundStarPayment": {"owner": 123, "chargeId": "…"}}'`
   (`chargeId` можно опустить — возьмётся последний). Подписка заканчивается сразу.
